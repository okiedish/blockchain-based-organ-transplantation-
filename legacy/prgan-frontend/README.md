
# PRGAN Frontend (prgan-frontend)

This is a prototype React frontend for a National Organ Donation & Transportation portal.
It uses React + react-router + Tailwind CDN for styling (no Tailwind build step).

How to run:
1. Make sure Node and npm are installed.
2. In the project folder run:
   npm install
   npm start

This will open the app at http://localhost:3000

Notes:
- Aadhaar auth is simulated with a dummy Aadhaar number + OTP flow (stored in localStorage).
- Backend / blockchain integration placeholders are included as comments and mocked functions.
- This project was prepared to be a drop-in folder (copy-paste into your machine).
